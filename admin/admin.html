📚 책장 어드민

사이트 미리보기 ↗
YES24 API 키가 아직 없어요. 책 검색을 하려면 키가 필요해요. 이 폴더의 .env.example 파일을 복사해서 이름을 .env로 바꾸고, 안에 키를 붙여 넣은 뒤 어드민을 껐다 켜 주세요. 키는 developers.yes24.com에서 받아요. 키 없이도 아래 "직접 적기"로 책을 꽂을 수 있어요.
지금 꽂혀 있는 책 중 권은 샘플이에요. 내 책을 몇 권 꽂은 뒤 지워 주세요.

1. 책 찾기

YES24에 없는 책은 직접 적기로 꽂을 수 있어요. 표지 대신 제목 카드가 나가요.

2. 책장에 꽂기

왼쪽에서 책을 찾아 표지를 누르면 여기에 입력 칸이 열려요.

내 책장

3. 웹에 올리기

게시를 누르면 docs/shelf.json이 새로 써져요. 여기까지는 내 컴퓨터 안의 일이에요. 사이트 미리보기로 확인한 뒤 GitHub에 올리면 웹에 반영돼요.

Claude Code(코덱스)에게 이렇게 말하면 돼요.

책장을 게시했어. 바뀐 파일을 커밋하고 GitHub에 올려줘.
올리기 전에 .env 파일이 올라가지 않는지 확인해줘.

직접 한다면 터미널에서

git add .
git commit -m "책장: 새 책"
git push

처음 한 번은 저장소를 만들고 GitHub Pages를 켜야 해요. README의 "웹에 처음 올리기"를 봐 주세요. push 하고 1~2분 뒤에 사이트가 바뀌어요.
